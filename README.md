# うちのこ（Uchi no Ko）🐾

## アプリ概要

「うちのこ」は、大切なペットの写真や動画をアルバムにまとめて保管・整理し、家族や親しい人と安心して共有できるアプリケーションです。  
SNSでは流れてしまいがちな日常の一コマも、アプリ内で **しっかり記録・振り返る** ことができます。

---

## 主な機能（基本機能）

- ユーザー登録 / ログイン / ログアウト（Devise）
- 写真・動画の投稿（ActiveStorage）
- アルバムの作成・編集・削除
- タイトル・説明文・日付の登録
- タグによる分類・検索機能
- コメント機能（投稿／削除）

---

## 今後の追加予定機能

- ✅ アルバム単位での一括ダウンロード機能（ZIP形式）
- ✅ アルバムごとの公開用パスワード設定機能（家族限定共有に対応）
- ✅ SNS共有機能（Instagram／Xなどへのリンク共有）
- ✅ カレンダー表示機能（思い出を時系列で振り返りやすく）

## アプリ開発の背景

SNSでは流れてしまいがちな「うちのこ」の日常を、**もっと丁寧に、安心して記録・共有したい**。  
そんな想いから本アプリの開発をスタートしました。  
タグや日付で整理した投稿を、家族とだけで共有できる――  
**「ちょうどいい記録アプリ」** を目指しています。

## セットアップ手順（開発環境）

```bash
$ git clone https://github.com/Haru-1210/uchi-no-ko.git
$ cd uchi-no-ko
$ bundle install
$ yarn install
$ rails db:create
$ rails db:migrate
$ rails s
